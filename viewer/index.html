Full screen

The 3D picture only works when it fills the whole display at 1 image pixel = 1 display pixel, so that the middle of the picture sits exactly on the hinge. Browser and system bars take part of the screen, which crops the picture and shifts it off the hinge.

Chrome

  1. If you added DuoVision to the home screen before, delete that icon first: it is an old shortcut that opens inside the browser.
  2. Open the site in Chrome, tap the ⋮ menu → Install app (or Add to Home screen → Install).
  3. Launch DuoVision from the new icon. It opens full screen in landscape with no browser or system bars. If bars still show, tap the picture once.

iPhone (Safari or Chrome)

  1. Tap Share → Add to Home Screen → Add, then launch DuoVision from the new icon.

Then hold the phone in landscape and check Settings → Diagnostics: “viewport covers” and “fits exactly” should both say YES.
